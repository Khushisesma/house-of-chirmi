# House of Chirmi

Marketing site for houseofchirmi.com — React + Vite, prerendered to static HTML (vite-react-ssg). Hosted on Vercel.

## Edit content
All text, prices, case studies and contact details live in **`src/content.js`**. Edit, commit, push to `main` — Vercel redeploys in ~1 minute.

Case-study images go in `public/images/` (WebP, ~1600px wide).

## Run locally
```
npm install
npm run dev
```
